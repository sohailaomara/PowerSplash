# PowerSplash

A growth-based survival game built in Unity 6.3 (URP), created for DMET 909.

## About the Game

You play as a small fish trying to grow into an apex predator by eating smaller fish and avoiding bigger ones. Eating certain rare creatures also grants temporary powers — like inflating, an ink cloud, or a speed boost — adding a bit of strategy to the usual eat-or-avoid loop.

## Built With
Unity 6.3 (Universal Render Pipeline)
